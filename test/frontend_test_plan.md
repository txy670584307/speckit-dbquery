# 前端测试计划

## 1. 概述

本文档描述 DB Query Tool 前端页面的测试范围、策略和方法。前端基于 Vue 2 + Element UI，部署于 `http://localhost:8080`。

## 2. 测试范围

| 组件/页面 | 说明 |
|-----------|------|
| **QueryPage.vue** | 主查询页面，组合所有子组件 |
| **DbList.vue** | 数据库连接列表 + 添加对话框 |
| **TableTree.vue** | 表/视图三级树展示 |
| **SqlEditor.vue** | Monaco Editor 封装 |
| **ResultTable.vue** | 查询结果动态表格 |
| **整体交互** | 模式切换、连接切换、状态管理 |

## 3. 测试策略

### 3.1 层级

- **组件测试**：独立验证每个 Vue 组件的渲染和交互
- **集成测试**：组件之间的协作（如 DbList 选中 → TableTree 更新）
- **端到端测试**：完整用户流程（添加连接 → 浏览表 → 执行查询 → 查看结果）

### 3.2 测试方法

- **功能验证**：手动操作 UI，验证显示和交互是否符合预期
- **视觉验证**：检查布局、样式、空状态、加载状态
- **错误验证**：模拟后端错误，检查前端错误提示和降级行为

### 3.3 前置条件

- 前端服务运行中（`http://localhost:8080`）
- 后端服务运行中（`http://127.0.0.1:8000`）
- PostgreSQL 容器运行中（有测试数据）

## 4. 测试环境

- 浏览器：Chrome / Edge 最新版本
- 屏幕分辨率：1920×1080（桌面端）
- 网络：localhost（无网络延迟）

## 5. 通过标准

- 功能完整：每个操作有正确反馈
- 状态一致：切换连接/模式时页面状态正确
- 容错：后端错误时前端不崩溃，有合理错误提示
- 视觉：空状态、加载状态、错误状态均有对应 UI
